# TheGrind

The Grind is a full-stack habit tracking web application designed to help users build consistent habits, track daily progress, maintain streaks, and review their habit history.

#
🚀 Live Demo

Frontend:
https://the-grind-eta.vercel.app/

Backend:
https://thegrind-production.up.railway.app

GitHub:
https://github.com/tanuelara-cmyk/TheGrind

## 🚀 Features

- User Registration
- User Login
- Habit Creation
- Mark habits as completed
- Edit and Delete habits
- Daily habit tracking
- Progress tracking
- Streak calculation
- Simple and responsive UI
- MySQL database for storing user and habit data
- REST API using Spring Boot

## 🎯 Project Objective

The main objective of The Grind is to understand how a frontend, Java backend, REST APIs, and a relational database work together to create a complete full-stack web application.
